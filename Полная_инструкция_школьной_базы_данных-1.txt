ВОЗМОЖНОСТИ ШКОЛЬНОЙ БАЗЫ ДАННЫХ

1. Добавить ученика
Создать новую запись: ФИО, дата рождения, класс.

2. Изменить ученика
Изменить телефон, адрес или другие данные.

3. Удалить ученика
Удалить запись ученика из базы.

4. Найти ученика
Искать ученика по ФИО или ID.

5. Добавить родителя
Создать контакт и привязать его к ученику.

6. Изменить родителя
Изменить телефон, email, адрес или другие данные.

7. Удалить родителя
Удалить неактуальную запись родителя.

8. Добавить учителя
Создать запись преподавателя: ФИО, должность, стаж.

9. Добавить класс
Создать класс и назначить классного руководителя.

10. Добавить предмет
Добавить школьный предмет и количество часов.

11. Добавить оценку
Записать новую оценку ученика по предмету.

12. Изменить оценку
Исправить ошибочно внесённую оценку.

13. Удалить оценку
Удалить ошибочную запись об оценке.

14. Посчитать средний балл
Рассчитать средний балл ученика или класса.

15. Вести посещаемость
Отмечать, был ученик на уроке или отсутствовал.

16. Отчёт по пропускам
Посчитать количество пропусков и посмотреть причины.

17. Работать с расписанием
Добавлять и изменять уроки, время, кабинет и учителя.

18. Управлять кабинетами
Добавлять кабинеты и хранить информацию о них.

19. Работать с домашними заданиями
Добавлять, изменять и удалять задания и сроки сдачи.

20. Связывать таблицы
Объединять данные: ученик → класс → оценки → родители.

21. Фильтровать данные
Например, показать всех учеников 9А.

22. Сортировать данные
Например, отсортировать учеников по ФИО или дате рождения.

23. Создавать отчёты
Например, получить общую информацию об успеваемости и посещаемости класса.


ПРИМЕРЫ ЗАПРОСОВ

1. Найти ученика → получить карточку ученика.
2. Показать родителей → получить ФИО, телефон, email и родство.
3. Показать оценки → получить предметы и оценки.
4. Посчитать средний балл → получить средний балл.
5. Показать пропуски → получить даты и причины отсутствий.
6. Показать расписание класса → получить уроки, время, кабинет и учителя.
7. Показать домашние задания → получить задания и сроки сдачи.
8. Показать учеников класса → получить список учеников.
9. Показать уроки учителя → получить расписание преподавателя.
10. Отчёт по классу → получить информацию об успеваемости и посещаемости.


==================================================
ЗА ЧТО ОТВЕЧАЕТ КАЖДОЕ ПОЛЕ В ТАБЛИЦАХ
==================================================

1. УЧЕНИКИ

ID — уникальный номер ученика в базе.
Full_Name — полное имя и фамилия ученика.
Birth_Date — дата рождения ученика.
Gender — пол ученика.
Phone — номер телефона ученика.
Address — адрес проживания ученика.
Class_ID — идентификатор класса, в котором учится ученик.
Enrollment_Date — дата зачисления ученика в школу.
Status — текущий статус ученика, например активный или отчислен.

2. УЧИТЕЛЯ

ID — уникальный номер учителя в базе.
Full_Name — ФИО учителя.
Phone — номер телефона учителя.
Email — электронная почта учителя.
Position — должность учителя.
Experience — стаж работы учителя в годах.

3. КЛАССЫ

ID — уникальный номер класса в базе.
Class_Name — название класса, например 9А.
Teacher_ID — идентификатор классного руководителя.
Student_Count — количество учеников в классе.
School_Year — учебный год.

4. ПРЕДМЕТЫ

ID — уникальный номер предмета.
Name — название предмета.
Description — описание предмета.
Hours_Per_Week — количество часов предмета в неделю.
Department_ID — идентификатор отдела или кафедры.
Status — статус предмета.

5. ОЦЕНКИ

ID — уникальный номер записи об оценке.
Student_ID — идентификатор ученика, получившего оценку.
Subject_ID — идентификатор предмета.
Teacher_ID — идентификатор учителя, который поставил оценку.
Grade — сама оценка ученика.
Grade_Type — тип оценки, например домашняя работа, контрольная или самостоятельная.
Date — дата получения оценки.
Comment — комментарий учителя к оценке.

6. ПОСЕЩАЕМОСТЬ

ID — уникальный номер записи посещаемости.
Student_ID — идентификатор ученика.
Subject_ID — идентификатор предмета.
Date — дата урока.
Status — статус посещения: был, отсутствовал или опоздал.
Reason — причина отсутствия или опоздания.

7. РАСПИСАНИЕ

ID — уникальный номер урока в расписании.
Class_ID — идентификатор класса.
Subject_ID — идентификатор предмета.
Teacher_ID — идентификатор учителя.
Room_ID — идентификатор кабинета.
Day — день недели.
Start_Time — время начала урока.
End_Time — время окончания урока.

8. КАБИНЕТЫ

ID — уникальный номер кабинета в базе.
Room_Number — номер кабинета в школе.
Name — название или назначение кабинета.
Floor — этаж, на котором находится кабинет.
Capacity — максимальное количество человек в кабинете.
Equipment — оборудование, находящееся в кабинете.

9. ДОМАШНИЕ ЗАДАНИЯ

ID — уникальный номер домашнего задания.
Subject_ID — идентификатор предмета.
Teacher_ID — идентификатор учителя, который выдал задание.
Class_ID — идентификатор класса, которому выдано задание.
Task — текст домашнего задания.
Assigned_Date — дата выдачи задания.
Due_Date — крайний срок сдачи.
Status — статус задания, например актуальное или закрытое.

10. РОДИТЕЛИ

ID — уникальный номер родителя в базе.
Full_Name — ФИО родителя или опекуна.
Phone — номер телефона родителя.
Email — электронная почта родителя.
Address — адрес проживания.
Student_ID — идентификатор ученика, к которому относится родитель.
Relationship — степень родства: мать, отец, опекун и т.д.
Status — статус контакта, например активный или неактивный.

==================================================
КАК СВЯЗЫВАЮТСЯ ТАБЛИЦЫ
==================================================

Student_ID связывает данные с конкретным учеником.
Teacher_ID связывает данные с конкретным учителем.
Class_ID связывает данные с конкретным классом.
Subject_ID связывает данные с конкретным предметом.
Room_ID связывает данные с конкретным кабинетом.

Например:
Ученики.ID → Родители.Student_ID
Ученики.ID → Оценки.Student_ID
Ученики.ID → Посещаемость.Student_ID
Классы.ID → Ученики.Class_ID
Учителя.ID → Оценки.Teacher_ID
Учителя.ID → Расписание.Teacher_ID
Предметы.ID → Оценки.Subject_ID
Предметы.ID → Расписание.Subject_ID
Кабинеты.ID → Расписание.Room_ID
